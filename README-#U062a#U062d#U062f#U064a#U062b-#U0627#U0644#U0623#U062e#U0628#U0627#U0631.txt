# تحديث صفحة أخبار جمعية نماء العطاوية

## الملفات التي تم تعديلها
- `news.html`: إضافة البحث والتصفية حسب تصنيف الخبر، واستبدال أسعار السوق الثابتة برسالة لا توهم بأنها بيانات مباشرة.
- `admin-dashboard.html`: إضافة واجهة إدارة الأخبار، مع نموذج النشر وجدول التعديل والحذف.
- `main.js`: تحميل الأخبار، البحث والتصفية، نشر الأخبار وتعديلها وحذفها، ورسائل أوضح عند تعذر الاتصال.
- `supabase-config.js`: تصحيح عنوان Supabase وصيغة إنشاء العميل، وإصلاح توليد اسم الملف عند رفع الصور.

## متطلبات Supabase
تتوقع الصفحة وجود جدول `news` بالأعمدة التالية:
- `id` (معرّف رقمي)
- `title` (نص)
- `category` (نص)
- `date` (تاريخ أو نص بصيغة YYYY-MM-DD)
- `content` (نص)
- `image_url` (نص، يقبل قيمة فارغة)

رفع الصور يتطلب وجود Storage bucket باسم `namaa-media` مع إعداد صلاحيات الرفع والقراءة المناسبة.

**تنبيه أمني:** لا تجعل سياسات Supabase تسمح لأي زائر بإضافة الأخبار أو تعديلها أو حذفها. تسجيل دخول الإدارة الحالي في الواجهة الأمامية وحده ليس مصادقة آمنة؛ ينبغي حماية عمليات الكتابة عبر Supabase Auth بسياسات RLS مناسبة أو عبر خدمة خلفية موثوقة. لم يتم تغيير صلاحيات قاعدة البيانات من هذا الأرشيف، ولم يمكن اختبار الاتصال الفعلي بمشروع Supabase من هنا.
