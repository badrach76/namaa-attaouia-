إعداد دخول الإدارة والرسائل وطلبات الانخراط

1) في Supabase > Authentication > Users أنشئ مستخدمًا مخصصًا للإدارة ببريد إلكتروني وكلمة مرور قوية.
2) عيّن app_metadata.role = admin لهذا المستخدم من واجهة موثوقة لإدارة المستخدمين (لا تضع service_role key في ملفات الموقع).
3) شغّل MIGRATION-ADMIN-MESSAGES-AND-MEMBERS.sql في SQL Editor.
4) سجّل الدخول إلى admin-login.html بالبريد وكلمة المرور الخاصين بحساب Supabase Auth.
5) إذا ظهر خطأ صلاحيات على جدول members، راجع حالة RLS والسياسات الموجودة قبل تعديلها؛ لا تفتح قراءة الجدول للعامة لأنه يحتوي بيانات شخصية وحقول دخول.

الأسعار الدولية:
المصدر الرسمي المتاح هو بوابة المفوضية الأوروبية لأسعار زيت الزيتون:
https://agridata.ec.europa.eu/extensions/DataPortal/olive-oil.html
تعرض المنصة رابط المصدر الرسمي ولا تخترع أرقامًا. الجلب الرقمي التلقائي إلى العارضة يتطلب ربط API الرسمي عبر وظيفة خلفية/Edge Function والتحقق من صيغة البيانات؛ لا يُدّعى أنه تم تفعيله في هذه النسخة.
